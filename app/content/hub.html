Preferences

Display

The images ship with the game library. If they have been removed to save space, the background cycles through nothing at all — turn this off to leave it plain.

Conversations

Messages exchanged during a remote game go through a relay that has no accounts and no passwords: whoever runs it can read what is left there. A shared key makes that content unreadable to the relay — and only to those who hold the key.

Generate one below, then send it ONCE to the people you play with, by any channel except the relay itself — a message, an e-mail. They paste it into the same field. From then on your games with them are protected without any further step.

One key for everyone you play with means everyone who has it could read your other conversations, if they knew which game to look at. A game can be given a key of its own from its chat window. Replacing the key below makes every earlier conversation unreadable — including for you.

Tabulon is a multi-platform desktop application to play board games, based on the Jocly library

Jocly and Tabulon are released under AGPL v3.0 license.

Main features :

  • 2D and 3D user interface available
  • Fully resizeable game windows
  • Possible moves preview
  • Game import/export
  • Clocked games
  • Rules available for every game
  • Multi-windows: any number of games can be launched simultaneously
  • Play locally, against the computer, or remotely over the Internet
